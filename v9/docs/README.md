## 推荐阅读顺序

1. 本工程 `README.md`（3 分钟建立全局印象）；
2. `模块阅读文档.md` §0 一页速查 → §1 的 **4 条握手约定**（不读这个直接看代码容易踩坑）；
3. §2~§8 按 `myCPU → 取指 → 译码 → 执行 → 访存 → 写回 → 冒险处理` 顺序看模块；
4. §9 上板改造的三个机制（load 数据只在 M3 可前递 / 重定向要一次性 / 不能靠拉低 valid 挡指令）；
5. §10 典型指令走查（含 load-use 冒险的逐拍波形）；
6. `syn/上板改造说明.md` 看"改了什么、为什么、还差什么"；
7. 要上手改代码就看 §4 改动清单，再对着 `改动diff` 逐行确认。

## 约定

- **命名风格一律不改**：模块名、信号名、`_next`/`_last` 后缀、`valid`/`ready` 语义都保持原样；
  改造新增的端口/信号（如 `load_use_stall`、`EXU_ctrl_valid`、`bp_redirect_pending`、
  `fetch_align`、`hold`）都带中文注释说明用途。
- **两份说明文档的分工**：`CPU设计说明.pdf` = 改造前；`模块阅读文档.md` = 改造后（权威）。
  两者冲突时以 `模块阅读文档.md` 为准。
- 所有通道（VCD、SVG 时序图）都是**改造后**重新生成的；历史调试波形已清理。
