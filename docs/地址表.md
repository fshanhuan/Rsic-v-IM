## MMIO 寄存器（基址 `SOC_MMIO_BASE` + idx×4）

| 地址 | 名字 | 说明 |
|---|---|---|
| `0x10000000` | `SOC_MMIO_IDX_TXDATA` | 0x00 WO  写 → 串口发送 |
| `0x10000004` | `SOC_MMIO_IDX_TXSTAT` | 0x04 RO  bit0 = 发送器忙 |
| `0x10000008` | `SOC_MMIO_IDX_RXDATA` | 0x08 RO  队头字节（不弹） |
| `0x1000000C` | `SOC_MMIO_IDX_RXSTAT` | 0x0C RO  bit0 = FIFO 非空, bit1 = 溢出过 |
| `0x10000010` | `SOC_MMIO_IDX_LED` | 0x10 RW  低 7 位驱动 LED |
| `0x10000014` | `SOC_MMIO_IDX_BOOTREQ` | 0x14 WO  写 1 → 重新引导 |
| `0x10000018` | `SOC_MMIO_IDX_RXPOP` | 0x18 WO  写 1 → 弹出队头 |
| `0x1000001C` | `SOC_MMIO_IDX_CTL` | 0x1C RW  控制（见上：无效/irq_ps/alive） |
| `0x10000020` | `SOC_MMIO_IDX_IRQPEND` | 0x20 RW  读=待处理位图；写 1s = claim（清位） |
