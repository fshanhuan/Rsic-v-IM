## P0-1　`debug_status` 的 X：根因是**软件跳了一条指令**，不是 RTL

### 现象（历史记录）

> 只要 `mstatus.MIE=1`，shell 的命令解析就全坏；`debug_status` 低两位（`dcache_hold` /
> `IFU_stall`）变成 **X**，CPU 从此不再发 MMIO 读请求。

### 三个真实原因（叠在一起才这么难查）

| # | 原因 | 后果 |
|---|---|---|
| ① | **同一个 RX FIFO 有两个消费者**：ISR 在往环形缓冲搬，`getc_nb()` 的"环空回退"又去 peek+pop | 字节重复（`i`→`i0`）、丢失、串入杂字符 |
| ② | **陷入处理对"中断"也做 `mepc += 4`**（规范只允许对同步异常/断点这么做） | 每次接收中断都**跳过一条被打断的指令**；被跳过的是 `sw` 时，之后 `lw` 读到从未写过的槽 |
| ③ | **测试台只清了 DRAM 低 16 K 字**（`for i<16384`），而栈顶在 `0x20000`（字 32768）向下长 | ②读到的"从未写过的槽"在仿真里是 **X** → X 顺着寄存器流进地址/控制 → `dcache_hold`/`IFU_stall` 变 X |

②+③ 合起来解释了"停顿网络出现未定义值"这个假象：**RTL 里根本没有 X，是软件跳了一条指令之后读到了仿真未初始化的存储。**

### 修法

- `sw/monitor.c` `trap_entry()`：中断分支**直接返回**，不动 `mepc`；只有断点命中和
  真正不认识的同步异常才 `mepc += 4`。顺带记录现场（`i` 命令打印 `exc n= / last= / @pc`）。
- `sw/monitor.c`：串口接收**默认走中断**（`#ifndef RX_IRQ_DISABLE`），
  编译时加 `-DRX_IRQ_DISABLE` 可退回纯轮询（保留给排查）。
- `sim/tb_monitor.sv`：DRAM **整块 32768 字**清零；新增 M9 检查
  `debug_status` 不许有 X。
- `sim/tb_monitor.sv`：第一条命令改成**等提示符之后再发**（12 ms）。原来 1 ms 就塞进
  8 深 FIFO，等于在赌"flush 与中断使能之间"的时序，测试本身不可靠。

### 证据

仿真（`_diag/sim_one.ps1 -Tb tb_monitor`，默认就是中断模式）：

```
[DBG] debug_status=00000080  wb_pc=00000438  mcause=8000000b  mepc=00000c68
[PASS] M1 banner printed        [PASS] M6 run executed app
[PASS] M2 'l 3f' replied        [PASS] M7 'ls' shows empty fs
[PASS] M3 'p 10000' replied     [PASS] M8 'df' shows 160 blocks
[PASS] M4 IROM window readable  [PASS] M9 no X on debug_status
[MONITOR-SELFCHECK] status=PASS (9 checks)
```

`mcause=0x8000000b` = 机器外部中断真的被取了；`debug_status=0x80` 完全定义。

真片：

```
> i
  rx irq ON   exc n=0 last=00000000 @0x00000000
> echo abcdefghij...(120 字符)
 abcdefghij...(逐字节一致回显 120 字符)
> k 20000
 cksum 0x717a93b5  (64 words @0x00020000)
```

`rx irq ON`：中断模式在跑；`exc n=0`：**零次同步异常**（②的 bug 会不断制造异常）；
120 字符长命令逐字节一致 → 每个字节一次中断，通路稳定。

## P0-2　`run <file>` 进仿真回归（容器端到端）

板子上早就验过，仿真里一直没验：要把 540 B 容器逐字节从串口喂进 shell，光那串十六进制
就要 105 ms 仿真时间（iverilog 下几十分钟）。

办法：`sw/mkfs.py` 直接把文件系统（超级块 + 目录 + 位图 + 数据块）烤成 DRAM 镜像，
`sim/tb_runapp.sv` 用 `+fs=` 一把装进去，然后只发一条 `run hello_app`。**程序侧一行不特判**，
走的就是真实的 `fs_find` → 容器头 → 校验和 → 写窗口/DRAM → `fence.i` → 入口 → 返回。

## P0-3　开机第一条命令偶发失效：已定位并修掉

根因：`rx_flush()` 原来放在**横幅之后**。横幅要打 10.6 ms，而引导期残留字节在开机瞬间
就进了 FIFO；等横幅打完再冲，冲掉的可能是"用户在横幅期间已经敲进来的字"。
反过来，如果完全不冲，"灌镜像时 console 接收器吃进去的字节"就会插进第一条命令
（`k 20000` → `k0 20000`）。

修法：`rx_flush()` 移到 **横幅之前、开中断之前**（顺序：flush → 开中断 → 打横幅）。
残留字节在 CPU 开始工作前就清掉，横幅期间到达的都是真实输入。

证据（每次都是刚引导完、**第一条**命令）：

```
=== reload 1 ===        === reload 2 ===
l 3f                     l 3f
 LED <- 0x0000003f        LED <- 0x0000003f
>                        >
```

2/2 命中。加上 P0-1 的 120 字符长命令，共 3 次引导、0 次失败。

## P0-4　lint 归零（并真抓到 4 个缺陷）

原来"lint"只有 iverilog，而 iverilog 对**隐式网络**极其宽容：先使用、后声明会被它
悄悄造成一根 **1 bit** 的隐式线，多 bit 信号于是被**截断**而不是报错。

用 Vivado `xvlog --sv`（真 SV 前端）跑 34 个设计文件，第一次就报 4 处：

| 文件 | 信号 | 问题 |
|---|---|---|
| `rtl/CSR.sv` | `trap_commit_eff` | 200 行使用、227 行才声明 |
| `rtl/myCPU.sv` | `lsu_req_seq` | 900 行使用、914 行声明 |
| `rtl/myCPU.sv` | `dcache_m1_hit/dcache_m1_rdata/LSU_Rdata_m1/MEM_m1_ok` | 421/848 行使用、915 行声明；其中两根是 **32 bit** |
| `board/board_top.sv` | `cpu_rst_eff` | 231 行使用、304 行声明 |

全部改成"声明在使用之前"（语义不变，都是 1 bit；但从此不再赌仿真器的宽容度）。

门禁：`_diag/lint.ps1`（已在 `regress.ps1` 里），**0 error / 0 warning** 才算过。

## P0-5　SVA 断言（xsim）

iverilog **不支持并发断言**，所以这套走 Vivado `xsim`：`sim/sva_soc.sv` 用 `bind` 挂到
`board_top` 和 `myCPU` 上，激励复用 `tb_irq`（irqtest：PLIC→MEIP→陷入→mret）。

| 断言 | 内容 |
|---|---|
| A1 | 总线方向互斥：`$onehot0({re_dram, re_code, we_dram, we_code, we_mmio})` |
| A2 | 片选时地址必须字对齐 |
| A3 | `boot_busy` 期间 CPU 必须被按住（IROM 单口不被两头抢） |
| A4 | `plic_irq == \|(pending & enable)`（组合一致性） |
| A5 | 复位后总线/PLIC 控制信号**不许有 X**（P0-1 的 RTL 版守卫） |
| A6 | 写 MMIO 不得与写 DRAM/代码窗口同拍 |
| C1 | 取指 PC 永远不许落进 MMIO 区（`< 0x1000_0000`） |
| C2 | 取指地址 4 字节对齐 |

**过程记录（值得留着）**：最初写的 C1 是"`dcache_hold` 期间 IFU_pc 不许动"，
第一次跑就报错——查下来是**我理解错了**：`dcache_hold` 只冻结 LSU/WBU，IFU 照常推进。
断言没抓住 RTL 的 bug，倒先抓住了写断言的人。改成"PC 不许进 MMIO"后通过。

```
[sva] xvlog (36 files)
[sva] xelab
[sva] xsim -runall
[sva] xsim rc=0  violations=0  tb_pass=1
[sva] PASS (no assertion fired, stimulus TB passed)
```

> 坑：`xelab` 拒绝混合 timescale（`rtl/add.sv` 没有 `timescale`），用
> `-timescale 1ns/1ps` 给默认值，不动 RTL。
