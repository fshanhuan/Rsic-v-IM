## 6. 命名与「状态行」约定

### 6.1 之前为什么会乱（如实记）

| 问题 | 例子 |
| --- | --- |
| 同一批工作出两份报告，名字几乎一样 | `P0_完成报告.md` 与 `P0P1_完成报告.md` |
| 版本号只出现在**部分**文件名里 | `模块速查_v17.md`、`产品手册_v18.md`，但 `模块说明.md` 也是 v13 时代的 |
| 「验收报告」有两份，分属不同项目 | `SoC_验收报告.md`（SoC 化）vs `记录仪_验收报告.md`（记录仪） |
| 记录仪文档后来才加进来，索引表没跟着改 | 本页 §1 原来只有 v17 时代的 20 行表格 |
| 计划表写着"未开始"，后来做完了没人回头改 | 方案 §3 的 S4~S8、产品手册 §10.6 的"S5/S7 未开始" |

### 6.2 现在的规则

1. **文件名**：`<产品线>_<主题>.md`；产品线是 `记录仪` / 不带前缀（= 处理器/SoC 本体）。
2. **每份文档标题下第一行**写 `> **状态**：<阶段>（日期）｜仍有效：…｜已被取代：…`。
3. **索引只在本页维护**，不在各文档里各写一份"目录"。
4. **数字只认 §1.2 的表**；引用旧文档的数字前先看它那行「状态」。
